# Планета ON — документация

Одностраничная афиша мировых культурных событий в стиле cifra.com: ночной 3D-глобус с огоньками событий, карусели-карточки с гигантскими буквами, геоперсонализация и живой поиск свежих событий через Kimi API.

## Стек

- **Фронтенд**: один файл `index.html` (~1,2 МБ) — весь CSS/JS инлайн, Three.js r152.2 с CDN, текстура ночной Земли встроена base64. Без сборки, без зависимостей.
- **Бэкенд**: `server.js` — чистый Node.js 20, ноль npm-зависимостей. Статика + JSON API + интеграция с Moonshot (Kimi).
- **Деплой**: GitHub `vladfa2010/EventOn` → авто-деплой на Render (Docker, порт 3000).

## Быстрый старт локально

```bash
cd app
set -a; . /mnt/agents/secrets/planeta-on.env; set +a   # MOONSHOT_API_KEY + MOONSHOT_BASE_URL
PORT=3100 node server.js
# открыть http://localhost:3100
```

Без ключа страница тоже работает (статика), но блок «Вокруг вас» покажет только базовую афишу с пометкой «Kimi недоступен».

# Дизайн и технологии «Art: on»

## 1. Дизайн-стиль

Стиль ориентирован на cifra.com: тёмная «ночная» тема, крупная плакатная типографика, яркие цветные карточки с гигантскими буквами, круглые кнопки-пилюли. Никаких теней-коробок и светлых панелей — всё построено на чёрном фоне и цветовых акцентах.

### Базовые принципы

- **Чёрный холст.** Фон страницы `#050505` — события «светятся» на нём, как огни ночной планеты в hero-блоке.
- **Карточка = афиша.** Скругление 26px, гигантская полупрозрачная буква на фоне, текстовый блок прибит к низу (тег → заголовок → дата загрузки).
- **Пилюли.** Все кнопки — `border-radius:999px`, без квадратных контролов.
- **Обводки сплошные.** Полупрозрачные (`#цвет66`) — штриховые не используем, это «не стильно».
- **Акцентный красный** — только для действий: кнопки, точка в логотипе, выделение текста, ::selection.

## 2. Цвета

### База

| Переменная | Значение | Роль |
|---|---|---|
| `--bg` | `#050505` | фон страницы |
| `--card` | `#1c1c1e` | карточка «gray», тёмные плашки |
| `--card2` | `#141416` | вторичные тёмные поверхности |
| `--ink` | `#f5f5f5` | основной текст |
| `--dim` | `#9a9aa0` | приглушённый текст, подписи |
| `--radius` | `26px` | скругление карточек |

### Акцентная палитра (6 цветов карточек)

| Цвет | Hex | Роль |
|---|---|---|
| red | `#ff2e2e` | главный акцент, кнопки, лого-точка |
| violet | `#8b80f9` | ИИ-элементы (значок «ИИ», заглушка поиска) |
| blue (peri) | `#7c8cf0` | холодный акцент, фокус инпутов |
| pink | `#ff5e8f` | «мостик» между красным и фиолетом |
| mint | `#3fe0c0` | холодный компаньон peri |
| gray | `#1c1c1e` | нейтральная карточка |

Цвета карточек назначаются циклом `PALETTE = ['red','violet','blue','pink','mint','gray']` — событию `i` достаётся `PALETTE[i % 6]`. Та же палитра используется для точек-событий на глобусе, так что карточка и её огонёк на планете совпадают по цвету.

### Полупрозрачные производные

- Обводки: `#цвет66` (например `#ff2e2e66` для карточки почты, `#8b80f966` для ИИ-заглушки).
- Свечения: `#цвет77`/`#цвет88` в `box-shadow` (логотип, значок ИИ).
- Вторичный текст на цветных карточках: `#ffffffb8`, `#ffffff80`, `#ffffff66`.

## 3. Типографика

Два шрифта с Google Fonts:

| Шрифт | Веса | Где используется |
|---|---|---|
| **Oswald** | 500, 600, 700 | заголовки, логотип, теги карточек, гигантские буквы, заголовки секций |
| **Inter** | 400, 500, 600, 700, 800 | основной текст, описания, формы, подписи |

Приёмы:

- Заголовки карточек и секций — Oswald, `text-transform:uppercase`, плотный `line-height:1.0–1.08`.
- Теги карточек — 13px, жирность 700, `letter-spacing:.18em`, uppercase.
- Гигантская буква (`.giant`) — Oswald 700, выходит за край карточки (`top:-8%; left:-4%`), полупрозрачная.
- Размеры заголовков — через `clamp()`, чтобы карточки одинаково смотрелись на мобильном и десктопе.

### Анатомия карточки

```
┌─────────────────┐
│ Г (гигантская буква, фон)      ДАТА │
│                 │
│                 │
│ ТЕГ · КАТЕГОРИЯ │
│ Заголовок Oswald│
│ загружено 9 авг │
└─────────────────┘
```

Все текстовые карточки (включая ИИ-заглушку и карточку почты) придерживаются одной компоновки: тег → заголовок → мелкая строка. У ИИ-заглушки верх текстового блока скриптом выравнивается точно по линии заголовка соседней карточки.

## 4. Анимации и «дорогие» детали

- **Глобус:** авто-вращение; при выборе гео — поворот к точке юзера по `easeInOutQuint` (1600 мс, плавный старт), пауза 500 мс после остановки, только потом скролл к «Вокруг вас».
- **Значок «ИИ»:** пульс `aiPulse` (1.6 с) — расходящееся свечение `#8b80f9`.
- **Карточки:** `hover → translateY(-6px)` за 0.25 с.
- **Появление гео-баннера:** `geoIn` 0.45 с, `cubic-bezier(.2,.9,.3,1)`.
- **Скролл:** `scroll-behavior:smooth`, карусели на `scroll-snap`.

## 5. Технологии

### Фронтенд

| Технология | Зачем |
|---|---|
| Один файл `index.html` (~1.2 МБ) | вся вёрстка, CSS и JS сайта — без сборщиков и фреймворков |
| Three.js 0.152.2 (cdnjs) | интерактивный глобус на WebGL: точки-события, вращение, фокус на гео |
| Base64-текстура Земли | зашита в файл — ночная планета грузится мгновенно, без внешних запросов |
| Google Fonts | Oswald + Inter |
| Нативный JS | карусели (scroll-snap), оверлей события, формы, опрос API — всё без библиотек |

Fallback: если WebGL недоступен — статичная заглушка «События ждут вас ниже», вся остальная страница работает.

### Бэкенд

| Технология | Зачем |
|---|---|
| Node.js 20, `server.js` | чистый `http`/`fs`/`path`, **ноль npm-зависимостей** |
| Moonshot AI API (`kimi-k2.6`, fallback `moonshot-v1-32k`) | поиск свежих событий по городу через `$web_search`; `thinking:{type:'disabled'}` для стабильности |
| Nominatim + Photon | серверный геокодинг координат → город (с фолбэком и circuit breaker) |
| `subscribers.csv` | сбор email подписчиков (append-only) |

Фоновые задачи: поиск ИИ идёт в фоне (до 8 минут, ретраи), фронт опрашивает `/api/around` каждые 10 секунд. Кэш результатов — 12 ч.

### Инфраструктура

| Компонент | Значение |
|---|---|
| Docker | `node:20-alpine`, `CMD ["npm","start"]`, порт 3000 |
| Хостинг | Render, автодеплой из GitHub (`vladfa2010/EventOn`, ветка `main`) |
| Секреты | ключ Moonshot — только в env (`MOONSHOT_API_KEY`), не в коде |

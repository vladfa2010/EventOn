# Карусели

На странице три карусели событий + навигационные кнопки «←/→» (`scrollBy 500px`). Все карточки строит одна функция `makeCard(ev)`.

## Анатомия карточки

```
┌─────────────────────────┐
│ [ГИГАНТСКАЯ БУКВА]      │  первая буква/слово title, прозрачность 40%
│              [бейдж даты]│  badge: «8 АВГ» / «СЕГОДНЯ» / «ЗАВТРА»
│                         │
│ ТЕГ · КАТЕГОРИЯ         │  tag
│ Заголовок события       │  title
│ загружено 9 авг         │  card-added — дата партии загрузки
│                     [→] │
└─────────────────────────┘
```

Цвет фона — из 6-цветной палитры `PALETTE=['red','violet','blue','pink','mint','gray']`, назначается по кругу `EVENTS[i % 6]` (равномерно, без повторов подряд). Клик → оверлей события.

## 1. Right Now (`#events`, `#carousel`) — главная лента

**Единственная** основная афиша (секции «Happening Soon» больше нет — объединена сюда).

- **Данные**: `FEED` = все события, кроме онлайн (`ONLINE_IDS`), отсортированные по дате загрузки: свежая партия первой.
- **Даты загрузки**: словарь `ADDED_BATCH` в коде — `{'2026-08-09': [id…12 событий арт-дайджеста]}`; всё остальное — `ADDED_DEFAULT='2026-08-08'` (стартовая подборка). Новый файл-список от редактора = новая строка в словаре.
- **Подзаголовок секции**: «Идёт сейчас · обновлено {дата самой свежей партии}» — вычисляется автоматически.
- Сейчас: 28 карточек.

## 2. Online (`#online`, `#carouselOnline`)

- **Данные**: `ONLINE` = события из `ONLINE_IDS` (`tv-stream`, `flip-flop`, `easel-view`, `libro-vasco`, `grammatica-aste`, `airless-tires`, `crip-exhibition`) — 7 карточек.
- Подзаголовок: «Смотри откуда угодно». Логика статична, без гео и ИИ.

## 3. «Вокруг вас» (`#around`, `#carouselAround`) — геоперсональная

Появляется только после гео (`onGeo` → `fillAround(lat, lng, near)`). Работает в две фазы:

### Фаза 1 — мгновенная (база + заглушка)

1. `cityName` — мгновенная оценка из локального словаря `nearestCityName`; параллельно `/api/geocode?lat&lng` возвращает точный город → обновляет пилюлю (`setLoc`).
2. **База**: события ≤500 км, ближайшие первыми (массив `near` уже отсортирован по haversine), максимум 8; к тегу добавляется «· N км». Если в радиусе пусто — 3 ближайших хотя бы.
3. **Карточка-заглушка «ИИ»** — первой: половинная ширина (`flex-basis: clamp(150px,17vw,235px)` — ровно 50% обычной), пунктирная рамка, пульсирующая пилюля «ИИ», текст «Мы ищем культурные события вокруг вас / Kimi изучает интернет — обычно до пары минут…».
4. **Карточка подписки** — второй (сразу за заглушкой): «Пришлём лучшее на почту», валидация email, `POST /api/subscribe`; при недоступном сервере — очередь в `localStorage.subQueue`; после успеха — «Готово ✦», при повторном визите — «Вы в списке ✦». Если поиск завершается неуспехом, карточка подписки возвращается в конец.

### Фаза 2 — опрос и перерисовка

1. Через 400 мс — первый `GET /api/around?lat&lng&city`, дальше опрос каждые 10 с (до 60 раз ≈ 10 мин).
2. **`pending`** → ждём дальше.
3. **Готово с событиями** → карусель **полностью перерисовывается**: только свежие находки Kimi (до 8), каждая с фиолетовым бейджем «ИИ» в углу, бейджем СЕГОДНЯ/ЗАВТРА, городом «площадка · город», ссылкой на источник; карточка подписки — в конце. Подзаголовок: «N свежих от Kimi (· кэш)». Найденные события также пушатся в глобальный `EVENTS`.
4. **Пусто** → подзаголовок «Kimi не нашёл свежего — показываем нашу базу», базовая раскладка остаётся.
5. **Ошибка** → честный текст «Kimi недоступен: {причина}», заглушка убирается.

### Пилюля локации

Слева от статуса — пилюля с пином и городом; клик открывает режим смены локации (см. [логика-главной.md](логика-главной.md)). После смены весь `fillAround` перезапускается с новыми координатами.
